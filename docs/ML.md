## 1. Machine Learning Honesty Charter

1. **Synthetic / Prototype Data Disclosure**:
   In Phase 0 through Phase 4, all training and evaluation datasets are generated by the physics-based flight mission simulator and synthetic fault injection engine. Every UI output and metric log MUST carry the tag:
   `DATASET_PROVENANCE: SYNTHETIC_SIMULATED_PROTOTYPE`
2. **Zero False Aerospace Validation Claims**:
   Never present synthetic benchmark accuracies (e.g., 99.2% classification accuracy on simulated misfire) as "certified aerospace reliability" or "flight-proven capability". Real aerospace flight deployment requires physical engine dynamometer validation and DO-178C / DO-254 compliance.
3. **No Fabricated Benchmarks**:
   Metrics must reflect actual cross-validation results run on generated flight sets, never hardcoded dummy scores.

## 3. Explainability Integration (SHAP)

SHAP values are computed with `shap.TreeExplainer(model)`:
$$\phi_i(x) = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F| - |S| - 1)!}{|F|!} \left[ f_x(S \cup \{i\}) - f_x(S) \right]$$

### Computational Budget & Latency Optimization
- **Risk**: Full Shapley computation on every 10 Hz frame causes thread starvation.
- **Optimization**:
  1. SHAP is calculated **asynchronously** via a dedicated Python worker thread pool (`concurrent.futures.ThreadPoolExecutor`).
  2. SHAP evaluation is triggered only when an anomaly is active, or throttled to at most once per second during steady-state cruising.
  3. The front-end receives cached attribution weights until the next background evaluation completes.

## 4. Remaining Useful Life (RUL) Modeling

The prototype degradation model calculates RUL based on cumulative thermal fatigue cycles and mechanical friction degradation:
$$\text{HealthIndex}(t) = 100.0 - \left( w_1 \cdot D_{\text{thermal}}(t) + w_2 \cdot D_{\text{lubrication}}(t) + w_3 \cdot D_{\text{vibration}}(t) \right)$$
Where:
- $D_{\text{thermal}}$ integrates high-CHT exposure hours (> 135 °C).
- $D_{\text{lubrication}}$ penalizes low-oil-pressure operations at high RPM.
- $D_{\text{vibration}}$ integrates cumulative high-RMS mechanical vibrations.

The RUL curve extrapolates the health degradation trajectory to the maintenance threshold ($\text{Health} = 60.0$) to estimate remaining flight hours.
